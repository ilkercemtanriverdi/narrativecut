NarrativeCut is designed for independent creators and small production teams working on long-form documentary and explainer content. It connects script, local media, timeline, subtitles, rights notes and optional rendering in one structured workflow.

About / Current status

Bootstrapped. Open source. Early-stage.

NarrativeCut is a bootstrapped early-stage project founded in 2026 by solo founder İlker Cem Tanrıverdi.

Project founding date: September 2026. Not yet incorporated. Current status: early-stage development.

Open-source core available on GitHub ↗ · Public releases ↗

The current core produces a deterministic timeline, subtitles and an asset-license report from scripts and rights-described local assets, with optional FFmpeg render and automated QC. Rights metadata records supplied descriptions; it does not verify legal ownership. An optional Claude-powered planning step is implemented: it groups script beats into editorial scenes and proposes visual roles, asset search queries and fact-checking risks as validated JSON. Feeding that plan into asset selection is the next step.

About / Current status

Bootstrapped. Open source. Early-stage.

NarrativeCut is a bootstrapped startup founded in September 2026 by solo founder İlker Cem Tanrıverdi, based in İzmir, Türkiye.

We are building documentary production tooling on Claude: Claude plans scenes and visuals, and a deterministic engine turns that plan into a reviewable cut.

Open-source core available on GitHub ↗ · Public releases ↗

The current core produces a deterministic timeline, subtitles and an asset-license report from scripts and rights-described local assets, with optional FFmpeg render and automated QC. Rights metadata records supplied descriptions; it does not verify legal ownership. An optional Claude-powered planning step is implemented: it groups script beats into editorial scenes and proposes visual roles, asset search queries and fact-checking risks as validated JSON. A saved plan now guides deterministic asset selection; on the demo it changes the chosen asset on 4 of 8 beats.

# Contributing

Thanks for helping improve FluxEngine Video Studio.

1. Create a focused branch from `main`.
2. Keep changes local-first and free of credentials, private data, and bundled media.
3. Add or update a focused test for behavior changes.
4. Run `python -m pytest` and the CLI smoke command in the README.
5. Explain rights metadata and any dependency changes in the pull request.

Please do not submit provider credentials, user data, or assets whose redistribution rights are unclear.
